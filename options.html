Deepgram Voice Notes

Configure your Deepgram API key for real-time transcription.

API Key

Create a free API key at console.deepgram.com. The key is stored only in your browser’s local extension storage and is never hardcoded or transmitted except to Deepgram’s servers.

Language

Choose how speech is transcribed. For mixed Urdu + English, use Mixed (code-switch). Note: Deepgram’s multilingual mode officially covers English, Hindi, and several other languages — pure Urdu script is best with the Urdu setting.

How it works

  • The extension uses an offscreen document to keep the microphone and MediaRecorder alive under Manifest V3.
  • Audio is captured in 250 ms WebM/Opus chunks via MediaRecorder.
  • Chunks are streamed over a WebSocket to Deepgram’s Live Transcription API (wss://api.deepgram.com/v1/listen).
  • Interim and final transcripts appear live in the popup.
  • Your API key is sent only as the WebSocket subprotocol (token, <key>) — the official browser authentication method.
