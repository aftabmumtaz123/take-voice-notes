TRANSCRIPT OUTPUT

Language & script

Roman / Latin

Use Roman / Latin output for mixed English + Hindi/Urdu conversations. English words are preserved. Native script keeps the transcript as returned by the transcription provider.

Roman mode is an offline phonetic transliteration layer. It does not translate the spoken language, so English remains English and mixed-language speech stays mixed.

CONFIGURATION

How to change providers

TRANSCRIBE_PROVIDER=assemblyai
TRANSCRIBE_FALLBACKS=deepgram,assemblyai,openai

Set your developer keys in .env, then run npm run build and reload the generated dist folder in Chrome.

SECURITY

Developer-managed credentials

There is no API-key form in the extension. Keys are injected at build time and are never requested from the end user.

For a public production extension, move provider authentication behind your own backend and issue short-lived client tokens. A packaged browser extension cannot make a long-lived secret completely invisible to its users.
